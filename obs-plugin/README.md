# VC Mix OBS plugin

The C++ plugin provides the **VC Mix** Tools menu and **VC Mix Participant** audio sources. Its Qt dialog inherits OBS's application theme, while a private local receiver supplies independent 48 kHz stereo PCM streams.

See the root [README](../README.md) for installation and setup, and [building instructions](../docs/building.md) for development.

The source identifier `discord_voice_participant` is retained for compatibility with existing OBS scene collections. The installed module and configuration directory use `vc-mix`.
